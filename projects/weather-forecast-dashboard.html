SkyPulse - Weather Forecast Dashboard

SkyPulse is a real-time weather dashboard built with React and Vite, featuring a sleek dark theme with dynamic gradient backgrounds that shift based on weather conditions and time of day.
It displays current conditions, a 5-day forecast, and hourly breakdowns with animated weather effects (rain, snow, fog) rendered on a canvas layer.
The app includes a detailed weather metrics grid showing temperature, humidity, wind, UV index, sunrise/sunset, and more — all fetched from the OpenWeather API.
Search any city with autocomplete suggestions and let the 60-minute auto-refresh keep data current.
Fully responsive, deployed via GitHub Actions to GitHub Pages.
