AuctionX - Auction Website

AuctionX is a dynamic online auction platform that enables real-time bidding on rare collectibles, fine art, antiques, and luxury items.
Built entirely with HTML, CSS, and JavaScript, it features role-based access for customers, sellers, and admins — each with tailored dashboards and workflows.
The platform handles live auction timers, automatic bid tracking, outbid notifications, multi-session account switching, and a complete payment-to-sold lifecycle.
Data persists seamlessly across sessions using localStorage and sessionStorage, eliminating the need for a backend server.
Deployed via GitHub Actions CI/CD on GitHub Pages, the project demonstrates a polished, production-ready interface with zero-downtime updates.
