## Features

- Responsive sidebar navigation with scroll-tracking active states
- Project showcase with detailed sub-pages
- Certificate gallery with lightbox preview and zoom controls
- Animated skill progress bars with intersection observer
- Contact form powered by Web3Forms
- Clean, modern UI with smooth transitions
